## About
Animated campaign website built for **Planilla Naranja**, a student representation initiative at Tecmilenio Torreón. It presents the team, proposals and campaign strategy through an original orange visual identity.

## Highlights
- Original campaign identity and editorial layout
- Animated hero and interactive cursor
- Proposal storytelling and team presentation
- Campaign roadmap
- Responsive design
- Instagram connection and calls to action
- Built as a real campaign communication asset

## Technology
Semantic HTML5 · CSS3 · Vanilla JavaScript · Responsive layouts

## Run locally
```bash
git clone https://github.com/abrilvillita/Campaign-Landing-Page.git
cd Campaign-Landing-Page
```
Open `index.html` in a browser.
